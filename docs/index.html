01 / GET STARTED

Installation

The npm package is @caliph71/carbon-canvas. Use Node.js 18+ or Bun. Rendering uses @napi-rs/canvas and syntax highlighting uses highlight.js. Supported platforms use prebuilt native binaries.

npm
npm install @caliph71/carbon-canvas
Bun
bun add @caliph71/carbon-canvas
Install from source instead
git clone https://github.com/cabrata/carbon-canvas.git
cd carbon-canvas
npm install

When working inside the cloned repository, use require('./') or import … from './index.mjs'.

Server-side rendering. This website is a static documentation gallery, not an in-browser renderer. Run render() in Node.js or Bun, including when using it behind an API.

02 / YOUR FIRST IMAGE

Quick start

Pass source code and options to render(). It returns a PNG Buffer synchronously, ready to save or send.

CommonJS · index.cjs
const fs = require('node:fs')
const { render } = require('@caliph71/carbon-canvas')

const code = `function hello(name) {
  return "Hello, " + name
}`

const png = render(code, {
  theme: 'dracula',
  language: 'javascript',
  fontFamily: 'Fira Code',
  lineNumbers: true,
  title: 'hello.js',
})

fs.writeFileSync('code.png', png)

Run node index.cjs and find code.png beside it. Without options, the renderer uses Seti, Hack at 14px, 56px padding, and a 2x export.

03 / MODULE SUPPORT

TypeScript & ESM

Named and default imports are available. Built-in types include RenderOptions, Theme, ThemeId, HighlightKey, and BuiltinFont.

TypeScript
import { writeFileSync } from 'node:fs'
import { render, type RenderOptions } from '@caliph71/carbon-canvas'

const options: RenderOptions = {
  theme: 'nord',
  language: 'typescript',
  windowTheme: 'boxy',
}

const png: Buffer = render('const count: number = 42', options)
writeFileSync('code.png', png)

In a Node TypeScript project, install typescript and @types/node as dev dependencies if they are not already present. There is no separate @types/carbon-canvas package to install. Use NodeNext resolution for Node projects, or bundler for a compatible bundler.

ESM · index.mjs (or a project with "type": "module")
import carbon, { render } from '@caliph71/carbon-canvas'
import { writeFileSync } from 'node:fs'

writeFileSync('code.png', render('console.log("hello")', {
  language: 'javascript',
}))
// carbon.render(...) works too

Bun

Bun can run TypeScript directly. The renderer has been tested with Bun 1.4.2 on Linux x64, including CommonJS, ESM, and all 29 themes.

index.ts · bun index.ts
import { render } from '@caliph71/carbon-canvas'

await Bun.write('code.png', render('console.log("bun")', {
  theme: 'nord',
  language: 'javascript',
}))

04 / REFERENCE

API reference

render(code, options?) → Buffer

code must be a string. All options are optional. An unknown theme or a non-string code argument throws an error. Dimensions are in logical pixels before applying scale.

Render options and defaults
OptionDefaultDescription
theme'seti'Built-in theme ID or a custom Theme object.
language'auto'highlight.js language name or alias, such as 'javascript', 'ts', or 'python'. Unknown names fall back to automatic detection.
fontFamily'Hack'Hack, Fira Code, JetBrains Mono, or a registered font.
fontSize14Font size in pixels.
lineHeight1.33Line height multiplier.
lineNumbersfalseDisplay line numbers.
firstLineNumber1Starting line number.
windowControlstrueDisplay window controls and the title bar.
windowTheme'none''none': macOS colors, 'bw': outline, 'boxy': Windows style.
title''Title centered in the header when window controls are enabled.
backgroundColor'rgba(171, 184, 195, 1)'Canvas-supported color string, or 'transparent'.
paddingVertical56Top and bottom padding in pixels.
paddingHorizontal56Left and right padding in pixels.
dropShadowtrueDraw a shadow beneath the window.
dropShadowOffsetY20Shadow vertical offset in pixels.
dropShadowBlurRadius68Shadow blur radius in pixels.
scale2Export scale, for example 1, 2, or 4.
minWidth90Minimum code window width in pixels.
maxWidth1024Maximum code window width. Longer lines are clipped.

Other exports

THEMES
Array of { id, name, highlights } theme objects. Useful for building your own theme selector.
DEFAULTS
The default render options.
FONTS
Array of the three bundled font names.
registerFont(path, name)
Register a local TTF/OTF file under a family name. Check that the file exists before rendering.

Customization

Custom theme

Provide id, highlights.background, and highlights.text. Unspecified token colors fall back to text.

JavaScript / TypeScript
render(code, {
  theme: {
    id: 'midnight',
    highlights: {
      background: '#1e1e2e',
      text: '#cdd6f4',
      keyword: '#cba6f7',
      string: '#a6e3a1',
      number: '#fab387',
      comment: '#6c7086',
      definition: '#89b4fa',
    },
  },
})

Custom font

Node.js
const { render, registerFont } = require('@caliph71/carbon-canvas')

registerFont('./fonts/CascadiaCode.ttf', 'Cascadia Code')
const png = render(code, { fontFamily: 'Cascadia Code' })

Transparent background

render(code, { backgroundColor: 'transparent', dropShadow: false })

05 / INTEGRATION

Send an image from an API

Rendering is synchronous. For a public endpoint, validate and cap code length, line count, and output size, and add rate limiting or a work queue. Never pass arbitrary untrusted render options straight to native canvas.

Example · npm install express @caliph71/carbon-canvas
const express = require('express')
const { render } = require('@caliph71/carbon-canvas')
const app = express()
app.use(express.json({ limit: '16kb' }))

app.post('/carbon', (req, res) => {
  const code = req.body?.code
  if (typeof code !== 'string' || code.length > 8000 || code.split('\n').length > 100) {
    return res.status(400).json({ error: 'Use a string of up to 8000 characters and 100 lines' })
  }
  try {
    const png = render(code, { language: 'javascript', scale: 1 })
    res.type('png').send(png)
  } catch {
    res.status(500).json({ error: 'Unable to render image' })
  }
})
app.listen(3000)

Good to know

  • This is a native server-side library, not a browser canvas bundle. GitHub Pages hosts only the documentation.
  • Automatic language detection can guess incorrectly for short snippets. Set language explicitly for reliable highlighting.
  • Tabs are converted to two spaces. Trailing whitespace is trimmed.
  • No soft wrap: text wider than maxWidth is clipped. Increase the width or break long lines yourself.
  • No background image or watermark support. Additional fonts can be registered locally.
  • Carbon themes with extra CSS use only their base colors here. Effects such as SynthWave glow are not included.
  • Native binary availability depends on the OS and architecture supported by @napi-rs/canvas. Node 18.20.8, Node 24, and Bun 1.4.2 runtime checks were run on Linux x64.

07 / CONTRIBUTING

Development & GitHub Pages

Run the checks

npm test
npm run test:types
bun test ./test.bun.ts
npm run test:docs
npm run themes

npm run themes regenerates the 29 images, the theme gallery on this page, and THEMES.md. Changes to the gallery should be made in scripts/themes.js.

Host these docs yourself

  1. Push your repository to GitHub.
  2. Open Settings → Pages → Build and deployment.
  3. Select Deploy from a branch, branch main, folder /docs, then Save.
  4. The site is served at https://<user>.github.io/<repo>/. No build command or framework is needed.

A .nojekyll file keeps the site fully static. All local asset URLs are relative so project subpaths work.
